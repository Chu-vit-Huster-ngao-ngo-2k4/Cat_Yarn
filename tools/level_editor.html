🐱🧶 Cat's Yarn — Level Editor

Vẽ level trực quan, tự động chấm "có giải được bằng logic thuần không" (mô phỏng đúng thuật toán trong script.js), rồi xuất thẳng ra JSON đúng định dạng để dán vào levels/. Chạy 100% trong trình duyệt — mở file này trực tiếp (double-click) là dùng được, không cần server.
